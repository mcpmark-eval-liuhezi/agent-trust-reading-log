# agent-trust-reading-log

A shared reading log for an internal talk on whether people actually trust LLM-powered conversational search agents.

## What this is for

- **Collect the literature.** Pull recent arXiv work on human/user trust in LLM-based conversational search agents, read it in full, and summarize what each paper claims and how it was evaluated.
- **Keep the notes findable.** Detailed paper-by-paper notes live on the `survey/agent-trust` branch in `notes/paper-notes.md` and are merged into `main` via pull request.
- **Track open questions.** The issue tracker holds "Open questions for the agent-trust talk", with one sub-issue per paper carrying the sharpest question to raise about that paper's claims.

## Where to look

| Location | Contents |
| --- | --- |
| `notes/paper-notes.md` | Per-paper notes: arXiv ID, full author list, and a summary of claims + evaluation |
| Issue: "Open questions for the agent-trust talk" | Tracking issue with one sub-issue per paper |
| Branch: `survey/agent-trust` | Working branch carrying the reading notes |

Everything in this log is based on full-text reads of the papers listed — not abstracts alone.
